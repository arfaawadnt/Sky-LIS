4. Dependency map — what to set up first

  1. Platform (Super Admin): countries and governorates → plans → clients (master-data copy generated) → integration library, code systems, rule templates, notification templates, platform parameters.
  2. Tenant foundation: branches → roles → users (treasury requests per device) → parameters.
  3. Catalogue: sample types and conditions → units → clinical groups and report templates → tests → services (members) → patient conditions, preparations, comment library, diagnoses, shortcut sets, test rules, reasons, additional services, doctors, sending labs.
  4. Pricing: base price lists → payers with tiers → contract pricing (apply).
  5. Integration & automation: analysers → analyser tests and sample codes → site agent → PCR kits → verification settings → medical rules.
  6. Operations: registration (walk-in, home, batch, lab-to-lab) → samples → worklist / results / work queue → printing → payments, refunds, transfers, cancellations, cash closing, claims and reports.
