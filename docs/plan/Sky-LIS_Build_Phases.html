1. Assumptions

  1. Stack per the workspace rules: .NET 9 Web API, Angular, PostgreSQL 17 (multi-tenant schema with tenant isolation), one site agent service for analysers. Indicative durations assume one team of 2 backend, 2 frontend, 1 QA and 1 product/analyst, working in two-week sprints.
  2. Every phase delivers working software against the prototype screens: the prototype is the UI contract, the requirements specification is the behaviour contract, and the comparison document is the scope list.
  3. A page is "done" when its API, UI (English and Arabic), validations, audit entries, printed documents and automated tests pass the exit criteria listed for the phase.
  4. Where an enhancement of an existing page needs master data that only exists on a new page (for example patient conditions for registration), the enhancement is built with a temporary seed and completed in the phase that delivers the page. These completions are marked "completes" in the tables.
  5. Durations are indicative for planning and must be re-estimated after Phase 0, when the team has measured its velocity on the real code base.

4. Risks & mitigations

RiskMitigation
Scope of the undocumented LDM modules (QC, outsourcing, SMS, online transfer)Decide in P0 with the product owner; QC is planned in P5, the others are out of the first release.
Printing hardware variety (label printers, barcode rendering)Printing service in P0 with built-in barcode rendering; test on the pilot laboratory's printers before P1 ends.
Analyser protocols differ per vendorDriver library in the site agent; start with the two analysers of the pilot laboratory; add drivers as separate work items.
Rule language misuse (auto-verification releasing a wrong result)Simulation mode and engine audit before enabling; roll out group by group; normal-range checker off by default.
Master-data update policy between platform and tenantsSettle the policy in P2 (open question OQ-03) before publishing global changes.
Arabic typography and RTL regressionsBoth languages are part of the definition of done for every page; automated RTL overflow checks in CI.
